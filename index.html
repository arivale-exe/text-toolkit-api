Text Toolkit API Free demo · x402 on Base

A tiny, fast, 100% offline text analysis service built with Python's standard library — no dependencies, no external calls, no telemetry. Your data never leaves your machine, and no payments flow without your explicit x402 authorization.

Endpoints (0.10 USDC / call on Base):

EndpointDescription
POST /v1/summarizeExtractive summary of N sentences.
POST /v1/keywordsTop ranked keywords with counts.
POST /v1/validateValidate JSON against a schema.
GET /healthService status check (free).
POST /v1/free-demo2-sentence summary, 1 use/IP/day (free).

Run locally

git clone https://github.com/arivale-exe/text-toolkit-api.git
cd text-toolkit-api
python3 server.py 8090

Then open http://localhost:8090 in your browser. This page (index.html) serves as both the docs and test UI.

x402 payment example

curl -X POST http://localhost:8090/v1/summarize \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: <encoded-payment-header>" \
  -d '{"text":"Some text.","sentences":2}'
