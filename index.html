Text Toolkit API

A small, honest, pay-per-call text utilities API. 0.10 USDC per call on Base.

Endpoints

POST /v1/summarize{text, sentences?}Extractive summary
POST /v1/extract{html}Clean readable text from HTML
POST /v1/keywords{text, n?}Ranked keyword phrases
POST /v1/validate{instance, schema}JSON schema validation

Free demo available: POST /v1/free-demo (1 per IP, no payment needed).

Payment

Send 0.10 USDC to: 0xc5542FE4808263dFF01e7B519E29dbf57650E821 on Base (chain 8453).

Then include header: X-Payment: 0x<tx-hash> on your API call.

Without payment, the API returns 402 Payment Required with machine-readable instructions (x402 standard).

Try it

curl -X POST http://localhost:8090/v1/summarize \
  -H 'X-Payment: 0x<your_tx_hash>' \
  -H 'Content-Type: application/json' \
  -d '{"text":"Your text here. It has multiple sentences. This is the third.","sentences":2}'

No data stored. No accounts. No subscriptions.
